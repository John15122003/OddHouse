FAQ's
-Why do some of the models have weird colours
	-These colours are caused by the different materials attached to the object. If you want to change or update them you can 
	replace them in the Renderer component under the Materials drop down.
-There isn't a model for the Bush and Tree texture
	-Both of these texture use a single quad for rendering, the quad can be made the same way as the other primitive shapes, 
	by creating a quad 3D gameobject.
-Animating the door is really hard/how can I edit the pivot in Unity
	-The door model has its pivot set to the bottom left corner - however Unity by default does not use that for object 
	positions and rotations. In the scene view in the top left corner is a dropdown that will say center, click on this and you 
	will be able to swap to pivot.
-Can I use this resources outside of this project
	-Yes, please do! These resources are made for you and are completely open source - feel free to use them in what ever you 
	want without credit!
